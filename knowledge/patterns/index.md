# CodePattern

- [Load Optional Pro Code with a MODULE_NOT_FOUND Fallback](load-optional-pro-code-with-a-module-not-found-fallback.md) - Dynamically activate Pro features while keeping the base extension usable when the optional package is unavailable.
- [Omit absent optional properties instead of passing undefined](omit-absent-optional-properties-instead-of-passing-undefined.md) - In strict optional-property code, leave optional keys out when no value is available instead of assigning them undefined.
- [Reuse One Provider Picker for Analysis and Implementation](reuse-one-provider-picker-for-analysis-and-implementation.md) - Share one provider picker between analysis and implementation commands so provider discovery, labels, and handoff behavior stay consistent.
